# English Notes

Tracks the working language set in `config.json` (English), for a native speaker of whatever `config.json`'s native language is (Russian). It records significant mistakes, recurring minor patterns, useful/idiomatic language that is easy to underuse as a non-native speaker, and vocabulary worth diversifying. Translate an entry into the native language and include examples in both languages wherever that genuinely clarifies the meaning; skip translation where it adds nothing, such as a pure form or spelling issue. This is a seed, not a finished analysis—it should get sharper as more evidence appears in conversation. Built alongside the standing “correct every prompt” habit.

## Recording threshold

- **Record any significant mistake immediately, even if it appears only once.** Significant means that it changes or obscures the intended meaning, exposes a grammatical misunderstanding worth correcting, or would be notably problematic in ordinary professional or native conversation.
- Record a minor error after it recurs enough to demonstrate a real pattern.
- Do not treat obvious one-off typos, transcription artifacts, or rushed spelling slips as learning gaps unless they recur.
- Do not let this file become only a collection of useful or “juicy” phrases: significant errors are higher-priority learning data.

**Vocabulary diversification stays out of the live conversation by default**—it accumulates here for review rather than being raised mid-discussion every time it comes up. Mention it live only when it is genuinely important enough to interrupt the technical conversation, which should be rare.

## Recurring patterns to watch

### Articles with mass/uncountable nouns
Russian has no grammatical article system at all (в русском языке нет артиклей) — this isn't a rule being misapplied, it's a category that just doesn't exist in the native grammar, which is exactly why it's hard. Shows up as dropping an article that's needed, or adding one that isn't, especially with nouns that are uncountable in English but might not obviously feel that way.

Seen: "Do I always run **a** C code like that?" → "Do I always run C code like that?"
RU: "код" (code) ведёт себя как неисчисляемое существительное в этом смысле — артикль не нужен, если только не имеется в виду конкретный *a piece of code* (кусок кода) или *a codebase* (кодовая база).

### Verb form slips under fast/casual typing
Seen: "I **touche** assembly a bit" → "I've **touched** assembly a bit" (past participle after "have," dropped the "-ed"). Only one data point so far — could just be a typing-speed thing rather than a real gap. Watching for whether this recurs before treating it as a pattern. (No translation needed here — this is a form/spelling issue, not a meaning issue.)

## Useful/"juicy" language worth having active

Not things you're necessarily missing — just natural, very common phrasing worth having ready rather than defaulting to a more literal/formal alternative:

- **"land"** (figurative) — "does that land more clearly?" / "that explanation didn't quite land."
  RU: в переносном смысле — «доходит», «заходит». Example: *"Does that land more clearly now?"* ≈ «Теперь понятнее? / Это заходит?»
  Extremely common native way to ask whether something actually made sense; a non-native default is often just "understand" or "clear."

- **"a bit of a stretch"** — a claim or comparison that's technically defensible but strained.
  RU: близкий идиоматичный эквивалент — «притянуто за уши» (буквально: "pulled in by the ears"), или мягче — «это уже некоторая натяжка». Example: *"Calling him an expert is a bit of a stretch."* ≈ «Называть его экспертом — это уже натяжка / притянуто за уши».
  Useful hedge when you want to agree-but-push-back at once.

- **"push back on"** — "you pushed back on that framing."
  RU: «возражать против», «не соглашаться с». Example: *"She pushed back on the proposal."* ≈ «Она не согласилась с предложением».
  Natural phrasal alternative to "disagreed with" or "objected to" — reads much more conversational.
